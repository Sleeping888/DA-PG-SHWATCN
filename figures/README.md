# Manuscript figures

Print-ready files supplied to the journal at 300 dpi. Figures 1-8 are 177 mm wide (2091 px); the
graphical abstract is 155.7 mm wide (1839 px) and is supplied as a single raster image.

| File | Content |
|---|---|
| `Figure_1.tif` | Architectural overview of the framework |
| `Figure_2.tif` | Physics-guided dynamic wake graph construction |
| `Figure_3.tif` | SDWPF layout and wind rose |
| `Figure_4.tif` | Dynamic graphs under three absolute inflow bearings |
| `Figure_5.tif` | Candidate physical wake scores and adaptive row-softmax coefficients |
| `Figure_6.tif` | Wake-pattern diagnostics |
| `Figure_7.tif` | Fusion-gate and turbine-role diagnostics |
| `Figure_8.tif` | Horizon-wise turbine and farm error on shared raw-valid labels |
| `graphical_abstract.tif` | Graphical abstract |

`Figure_1_source.emf` is the editable vector source of Figure 1. Figures 3-8 are plotted from the
prediction and diagnostic files in `reports/figures/` and `predictions/`.
